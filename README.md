# mimogoshi

Un tamagotchi de una sola página (HTML/CSS/JS puro, sin build, sin frameworks).

Cuida a tu mascota pixel-art: aliméntala, juega con ella (minijuego de atrapar
estrellas), límpiala, déjala dormir y cúrala si se enferma. Crece de huevo a
adulto según cómo la cuides. Todo el progreso se guarda en `localStorage` del
navegador — no hay servidor ni backend.

Abre `index.html` en el navegador para jugar.
